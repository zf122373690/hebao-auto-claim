# 和包自动领券 · Web 控制台

基于中国移动「和包」协议版自动领券脚本改造的 Web 版本：网页实时显示状态、自动登录、自动识别短信验证码（支持外部 Webhook 主动拉取）、多账号、定时自动运行。

> ⚠️ 本项目仅供学习交流使用，请遵守中国移动相关服务条款，勿用于商业用途或非法目的。

## 功能特性

- **Web 控制台**：实时日志、运行状态、商品勾选、兑换间隔设置
- **自动登录**：短信验证码自动识别（登录码严格 6 位 / 兑换码严格 4 位）
- **外部 Webhook 主动拉取**：配置地址后程序自动轮询读取验证码，全程无需手动粘贴
- **多账号**：登录会话自动保存，会话过期自动重新登录
- **定时自动运行**：每日定时 / 每 N 分钟，自动处理选定账号
- **智能失败处理**：
  - 当日领取次数已达上限 → 自动跳过该商品，不再浪费验证码
  - 验证码发送频繁 → 自动等待 120 秒后重试
  - 连续多个商品失败 → 疑似会话失效，自动重登后重试

## 原理

1. 手机短信转发 App 把收到的短信 POST 到本程序 Webhook（或平台存证后由程序主动拉取）
2. 程序识别验证码 → 自动登录 → 逐个商品自动领取
3. 每个商品领取需要**独立的新验证码**（4 位），程序自动等待并读取，绝不复用旧码

## 前置准备：短信转发器

本程序依赖**外接短信转发器**将手机收到的验证码实时传送到 Webhook。可选以下方案：

- **手机 App 版**：在备用 Android 手机上安装短信转发 App（如"短信转发器"等），将指定号码的短信自动 POST 到程序 Webhook 地址。
- **硬件转发器**：使用 SIM 卡短信转发硬件设备，推荐 **[dkb.cc.cd](https://dkb.cc.cd)**，插卡即用、无需常驻手机 App。

> 无论哪种方案，转发地址填 `http://<服务器IP>:<端口>/api/hooks`（或配置 `WEBHOOK_URL` 环境变量指向隧道地址，由程序主动拉取）。

## 快速开始

### macOS / Linux 一键启动

```bash
bash start.sh
```

### Windows 一键启动

双击 `start.bat`（或在命令行执行）。

> 首次运行会自动创建虚拟环境、安装依赖并启动；之后每次一键启动即可。

### 手动启动（可选）

```bash
# macOS / Linux
python3 -m venv .venv
.venv/bin/pip install pycryptodome
PORT=8000 .venv/bin/python web_hebao.py

# Windows
py -3 -m venv .venv
.venv\Scripts\pip install pycryptodome
set PORT=8000 && .venv\Scripts\python web_hebao.py
```

## 配置

### 端口

默认 `8000`，可用环境变量覆盖：

```bash
PORT=9999 .venv/bin/python web_hebao.py
```

### 外部 Webhook（自动拉取验证码，推荐）

把短信转发到隧道/转发平台后，把地址告诉程序：

```bash
WEBHOOK_URL="https://你的隧道地址/api/hooks" PORT=9999 .venv/bin/python web_hebao.py
```

配置后程序会**主动轮询**该地址的列表接口（`GET /api/hooks` 返回 JSON 数组，最新在前）自动读取验证码，无需任何手动操作。

### Webhook 接收格式（程序自带地址）

短信转发 App 填：`http://<服务器局域网IP>:<端口>/api/hooks`（兼容 `/`、`/webhook/sms`）

- JSON：`{"text": "【权益平台】您的验证码：6170，十分钟内有效"}`
- 表单 / 纯文本 / `?code=6170` 均可

## 页面功能

- **账号管理**：添加多账号、登录会话自动保存、删除账号
- **选择账号/手机号**：勾选「复用会话」跳过登录
- **商品选择**：单选 / 多选、每个商品重复次数、兑换间隔（默认 60 秒，平台要求约 1 分钟）
- **定时自动运行**：每日定时（HH:MM）或每 N 分钟，选定账号 + 商品自动执行
- **运行日志**：实时滚动

## 常见问题

| 问题 | 处理 |
|---|---|
| 核心依赖缺失: No module named 'Crypto' | 用一键脚本启动（会自动装依赖），或手动 `pip install pycryptodome` |
| 提示找不到 Node.js | 安装 Node.js：https://nodejs.org |
| 登录码 / 兑换码位数不对 | 程序已按「登录 6 位、兑换 4 位」严格匹配，不会混读 |
| 领取失败（API返回: None） | 该商品当日领取次数已达上限（默认 3 次），程序会自动跳过进下一个 |
| 验证码发送频繁 | 程序自动等待 120 秒后重试发送 |
| 公网隧道收不到短信 | 隧道需把请求转发到本程序端口；本机/局域网可直接访问 |
